# 数据资产清单

本目录为技能内的 `assets/data/`；表中所有资料均随技能保存。查询脚本见 [脚本用法](../../references/tools.md)。资料覆盖 S32K3xx，不表示本技能支持范围已超出 S32K310/311/312/314。

本地 PDF 版本（已读取封面）：
- `S32K3XXRM.pdf`：Rev.12，2025-11-11；5394 个 PDF 页面。
- `S32K3xx.pdf`：Rev.14，2026-04-10；170 个 PDF 页面。
- `S32K311_0P98C.pdf`：S32K310/311 mask `0P98C` 勘误，Rev.6，2025-07-24；14 个 PDF 页面。
- `S32K312-0P09C-ERRATA.pdf`：S32K312 mask `0P09C` 勘误，Rev.9，2025-07-24；17 个 PDF 页面。
- `S32K3X4-0P55A-1P55A-ERRATA.pdf`：S32K314/324/344 mask `0P55A`、`1P55A` 勘误，Rev.4，2025-07-24；27 个 PDF 页面。

RM 和数据手册封面列出的系列覆盖：S32K310、311、312、314、322、324、328、338、341、342、344、348、356、358、388、389。模块/参数及封装可用性仍需针对具体型号核对。新增勘误仅适用于各自封面列出的产品和 mask；当前版本未与厂商最新资料比对。XLSX 单独修订与原始下载链接未登记，不从文件名推断版本。

IOMUX 查询使用共用工作簿的主型号 Sheet，输出是候选数据，见 [IOMUX 查询说明](../../references/local-sources.md#iomux-共用工作簿)。
